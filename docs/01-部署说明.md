# 部署说明

Linux 服务器配置与管理 · 考试系统。原生 PHP + MySQL，无需 Composer，CSS/JS 全部自写，**不依赖任何外网 CDN**，机房内网可直接跑。

## 一、环境要求

| 项目 | 要求 | 说明 |
|---|---|---|
| PHP | 7.0 及以上（推荐 7.4 / 8.0 / 8.1 / 8.2） | 需 `pdo_mysql`、`mbstring`；`fileinfo` 可选（识别附件真实类型） |
| MySQL | 5.7 / 8.0，或 MariaDB 10.3+ | 字符集 utf8mb4 |
| Web 服务器 | Apache（phpstudy / XAMPP 均可）或 Nginx | 需支持 PHP |
| 浏览器 | Chrome / Edge 新版本 | 学生端要用到剪贴板粘贴，建议 Chrome |

## 二、目录结构

```
Linux-exam/
├── index.php              登录页
├── password.php           修改密码
├── logout.php             退出
├── install_check.php      环境自检（正式使用前删除）
├── .htaccess              Apache 安全策略
├── nginx.htaccess         Nginx 等价配置（复制进 server 块）
├── config/config.example.php  ★ 配置模板（可入库）
├── config/config.php      ★ 真实配置（不入库，.gitignore 已排除）
├── lib/                   核心库（config/bootstrap/db/auth/helpers/content/grading）
├── api/                   答题页用到的接口（保存、上传、心跳、交卷、日志）
├── student/               学生端（我的考试 / 答题 / 交卷结果）
├── teacher/               教师端（看板 / 阅卷 / 导出 / 打包）
├── admin/                 管理端（考试、组卷、题库、用户、设置）
├── assets/css|js          样式与脚本
├── uploads/               实操题附件（按 考试/学生/题目 分层存放）
├── sql/install.sql        建库建表脚本（幂等，可重复执行）
└── docs/                  这份文档所在目录
```

## 三、部署步骤

### 1. 放好文件

把整个目录拷到 Web 根目录下，例如：

- phpstudy：`D:\phpstudy_pro\WWW\linux-exam`
- XAMPP：`D:\xampp\htdocs\linux-exam`

### 2. 建库建表

用 phpMyAdmin 导入，或命令行：

```bash
mysql -u root -p < sql/install.sql
```

脚本会创建数据库 `linux_exam`、11 张表，并写入两个初始账号。

> 库名可以改，改完记得同步 `config/config.php` 里的 `db.name`。
> 脚本是幂等的（`CREATE TABLE IF NOT EXISTS` + `INSERT IGNORE`），重复执行**不会删数据**；如需清空重来，先备份再执行文件末尾注释掉的「强制重建」段。

### 3. 准备配置

仓库里只有模板 `config/config.example.php`。复制一份改名：

```bash
cp config/config.example.php config/config.php     # Linux
copy config\config.example.php config\config.php   # Windows
```

打开 `config/config.php`，只改这几处：

```php
'db' => array(
    'host' => '127.0.0.1',
    'port' => 3306,          // 你的 MySQL 端口
    'name' => 'linux_exam',
    'user' => 'root',
    'pass' => 'root',        // phpstudy 默认 root；XAMPP 默认留空 ''
),
'site' => array(
    'base_url' => '',       // 装在子目录时填 '/linux-exam'，装在根目录留空
    ...
),
'debug' => false,           // 正式开考前保持 false
```

> `config/config.php` 已在 `.gitignore` 里，不会被误提交到仓库。
> 缺这个文件也能跑自检页（会回退到模板配置），但只会报数据库连接失败。

### 4. 跑一遍自检

浏览器访问 `http://你的地址/install_check.php`，逐项确认：

- PHP 版本、`pdo_mysql`、`mbstring` 全部 ✔
- `uploads/` 目录可写（Windows 下一般默认可写；Linux 需 `chmod 755` 或给 www 用户写权限）
- 数据库连接成功、11 张表齐全

若登录时提示密码错误（换了 PHP 版本导致哈希不匹配），点页面上的「重置初始密码」即可重新生成。
> 重置按钮要求管理员已登录并带 CSRF token，未登录访问无效。

### 5. 登录

| 账号 | 初始密码 | 角色 |
|---|---|---|
| admin | Admin@123 | 管理员（建考试、管题库、管用户） |
| teacher | Teacher@123 | 教师（看板、开考、阅卷、导出） |

**首次登录会强制改密码**。若想让全班学生直接用初始密码进场，可在「系统设置 → 首次登录强制改密码」里关掉。

### 6. 导入题库

登录后台 → 题库管理 → 批量导入 CSV，上传你自己的题库 CSV（16 列格式见教师手册）。

## 四、正式开考前必做

1. `config/config.php` 里 `debug` 保持 `false`；
2. 改掉 admin / teacher 的初始密码；
3. 删除 `install_check.php`（它会重置密码，留着有风险）；
4. 用 phpMyAdmin 或 `mysqldump` 备份一次数据库，并把 `uploads/` 整个拷走。

## 五、常见问题

**Q：页面样式空白 / 按钮没反应？**
检查是否访问的是子目录但 `base_url` 没填，导致 CSS/JS 404。

**Q：学生上传大附件失败？**
两处限制取小值：① 后台「系统设置 → 单个附件上限」；② php.ini 的 `upload_max_filesize` / `post_max_size`。后者要改 php.ini 并重启 Apache。

**Q：学生交卷后说看不到分数？**
这是本系统的刻意设计——交卷页只显示「交卷成功」，学生列表也不显示得分列。成绩由教师统一公布。

**Q：一个账号在两台电脑登录会怎样？**
后登录的把先登录的顶下线（单点登录）。可在 `config/config.php` 的 `site.single_session` 关掉。

**Q：`uploads/` 里的文件能被直接访问吗？**
能（教师阅卷要靠它显示图片），但 `.htaccess` 已禁止该目录执行任何脚本，上传接口也拒绝 `.php/.phtml/.html/.svg` 等类型。

**Q：换电脑 / 换机房怎么办？**
拷三样东西：数据库（mysqldump 或 phpMyAdmin 导出）＋ `uploads/` 目录 ＋ 新的 `config/config.php`。改数据库账号即可。

## 六、Apache 安全策略（.htaccess）

仓库自带的 `.htaccess` 做了四件事：

- 禁止列目录（`Options -Indexes`）
- 禁止下载 `sql/md/txt/log/ini/sh` 文件（`FilesMatch` + `Require all denied`）
- 禁止直接访问 `lib/ config/ sql/ _tools/` 目录（`mod_rewrite` 规则）
- `uploads/` 目录关闭 PHP 引擎、禁止执行 CGI，并禁止其中再放 `.htaccess` 覆盖

`config/`、`lib/`、`sql/` 各自还带了一个 `.htaccess`，即使根规则不生效也单独拒绝访问。

Nginx 不认 `.htaccess`，需要按 `nginx.htaccess` 里的 server 块配置。

## 七、其它安全说明

- **进行中的考试不能删除**：管理后台会拦下来，提示先去考试看板「统一收卷」。
- **「延长」只对考试中的生效**：已结束的考试不会被重新激活成 running。
- **打包全班答卷有内存保护**：超过 `embed_image_max_kb`（默认 4MB）的图片不再 base64 内嵌，改为原样放进 ZIP 的 `images/` 子目录、HTML 用相对路径引用。非图片附件（docx/zip/txt 等）一律外置。
- **CSV 导入按行解析**：字段内不能直接断行，多条内容用全角「；」分隔。
- **导出含附件数列**：CSV / XLS 导出与看板都显示每人上传的附件数，便于核对谁漏传。
