# 学生须知

## 一、登录

用浏览器（建议 Chrome 或 Edge）打开考试系统地址，输入**学号**和**密码**登录。

首次登录会被要求改密码：输入原密码 → 输入两次新密码 → 保存。新密码至少 6 位。

## 二、进入考试

登录后看到「我的考试」，找到本场考试：

- 状态显示「待开考」→ 还没有开考，等老师发令
- 状态显示「考试中」→ 点**进入考试**
- 中途刷新或退出过 → 点**继续答题**，进度和计时都还在

**开考即开始计时，中途不能暂停，时间到系统自动交卷。**

## 三、答题

### 单选题 / 判断题

点选项即可，选中后立刻自动保存（右上角会显示「已自动保存」）。

### 简答题

在文本框里直接写，可分条（①②③）。停止输入约 0.7 秒会自动保存。

### 实操题（重点）

每道实操题分四部分：

1. **任务要求** —— 老师给你的操作步骤，照着在虚拟机的 CentOS 8 里做
2. **需提交的截图 / 附件** —— 清单，① ② ③ 逐项准备，别漏
3. **文本作答框** —— 写你的操作思路、关键命令；报错就把报错原文抄进来
4. **我的附件** —— 真正交截图和文件的地方

#### 交截图的两种方式

**方式 1：直接粘贴（最快，推荐）**

1. 用截图工具（Windows 自带 `Win + Shift + S`）截取命令与返回结果
2. 点一下实操题的文本作答框
3. 按 `Ctrl + V`
4. 缩略图出现在「我的附件」里就成功了

**方式 2：选择文件上传**

点「点击选择文件上传」→ 选中文件（可多选）→ 自动上传。
**文件类型不限**：png/jpg 截图、txt 命令记录、pdf、docx 报告、zip 打包都可以，单个不超过 20MB，每题最多 6 个。

也可以直接把文件**拖到题目卡片上**，效果和选择文件一样。

#### 提交要求

- 截图要能看清**命令与返回结果**，不要只截一半
- 文件名建议带上题号与学号，例如 `5-1_命令结果_2510101.png`，教师核对快
- 图片点一下可以放大查看；传错了点右上角 × 删除，然后重传

## 四、答题卡

右侧（手机上是顶部）有题号网格：

- 绿色 = 已答（写了文字、选了选项，或传了附件）
- 灰色 = 未答

点题号可跳到该题。**未答题目也可以交卷，但会在确认框里提示还有几题没答。**

## 五、交卷

点右上角或页面底部的**交卷**按钮，确认后即完成。

注意：

- 交卷后**不能再修改答案**，附件也传不了
- 交卷页只显示「交卷成功」，**不显示试卷内容，也不显示分数**
- 成绩由任课教师评阅后统一公布

## 六、注意事项

1. **不要中途关浏览器**。真关了也不要紧，答案一直在自动保存，重新登录点「继续答题」即可，但计时不会重来。
2. **不要频繁切换窗口**。系统会记录切屏次数，超过阈值会弹提醒并记入监考看板。
3. **操作前先看清楚题目要求**。虚拟机里只操作老师指定的磁盘，不要动系统盘。
4. **报错是正常现象**，把报错原文写进作答框并截图，反而是加分项。
5. 网络断了先别慌，恢复后刷新页面继续答，已保存的内容都在。
6. 有问题举手找监考教师，不要自己重启电脑。
