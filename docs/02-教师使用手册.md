# 教师使用手册

## 一、角色与入口

| 角色 | 登录后进入 | 能做什么 |
|---|---|---|
| 管理员 admin | 管理后台 | 建考试、组卷、题库、用户与班级、系统设置 |
| 教师 teacher | 考试看板 | 开考/收卷/延时、强制交卷、阅卷、导出成绩 |
| 学生 student | 我的考试 | 答题、粘贴截图/上传附件、交卷 |

教师账号也能进阅卷和看板；管理后台只对管理员开放。

## 二、题型

本系统只有四种题型：

| 题型 | 判分方式 | 学生作答形式 |
|---|---|---|
| 单选题 | 系统自动 | 四选一（选项数可 2~8） |
| 判断题 | 系统自动 | √ / × |
| 简答题 | 教师按评分点打分 | 文本作答 |
| 实操题 | 教师按评分点打分 | 文本说明 **＋ 截图（可 Ctrl+V 粘贴）＋ 任意类型附件** |

没有多选题。若从旧系统迁移，多选题需拆成单选或判断题。

## 三、题库

### 3.1 单题录入

题库管理 → 新增题目。选题型后表单会自动切换：

- **单选题**：填选项（每行一个，自动编号 A/B/C/D）＋ 正确答案（如 `B`）
- **判断题**：选「正确 √」或「错误 ×」
- **简答题 / 实操题**：填参考答案 ＋ 评分点
- **实操题**额外有：任务要求（贴给学生看的步骤）＋ 需提交的截图/附件清单（自动加 ①②③）

评分点写法：每行一条，格式 `要点描述 | 分值`，例如

```
创建 pv / vg / lv 三步齐全且顺序正确 | 3
写出格式化与挂载 | 1
提到写入 fstab 或扩容方法 | 1
```

**评分点分值之和建议等于该题默认分值**，这样阅卷时点「满分」一键就是整题满分。

### 3.2 批量导入

题库管理 → 批量导入 CSV。共 16 列，顺序固定：

```
type, chapter, topic, difficulty, stem, optA, optB, optC, optD,
answer, analysis, ref_answer, rubric, pract_steps, pract_shots, score
```

注意点：

- `type` 填 `single / judge / short / practical`，也认「单选」「判断」「简答」「实操」
- `answer`：单选写 `B`；判断写 `T` / `F`（也认「对」「错误」）
- `rubric`、`pract_steps`、`pract_shots` 里要多条时**用全角「；」分隔**，导入后自动转成换行（CSV 是逐行解析，字段内不能直接换行）
- 编码 UTF-8 或 GBK 都行，程序会自动识别；重复导入会产生重复题目（不做去重）

页面右下角有「下载 CSV 模板」，含四种题型各一条示例。

## 四、新建考试（组卷）

管理后台 → 新建考试，分四步。

### 第 1 步：基本信息

填考试名称、科目、时长（分钟）、卷面总分、计划开考时间（仅作提示）、考前须知。

### 第 2 步：组卷 —— 这是重点

进入组卷页后有两种组卷方式，可以先批量再微调。

#### 方式 A：整卷快捷组卷（最快）

页面顶部的蓝色面板。给每个题型填「几题 × 几分」，点**一键随机抽题**：

```
单选题 20 题 × 1 分
判断题 10 题 × 1 分
简答题  4 题 × 5 分
实操题  5 题 × 10 分
→ 合计 100 分
```

系统会从题库**随机**抽取（替换掉当前整卷的选择），并按题型自动排号。
库存不足时会提示，并把该题型全部选上。

#### 方式 B：按题型批量选题（可控）

每个题型下面都有一条批量操作栏：

| 控件 | 作用 |
|---|---|
| 数量 | 要抽几题 |
| 难度 | 全部 / 易 / 中 / 难，只在此范围抽 |
| 章节 | 只从某个项目（章节）里抽 |
| **随机抽 N 题** | 在筛选范围内随机取 N 题，替换本类已选 |
| **顺序取前 N 题** | 在筛选范围内按题库顺序取前 N 题 |
| 全选 / 清空本类 | 按当前筛选条件全选或清空 |
| 统一分值 + 套用到已选 | 把本类已勾选题目的分值一次性改掉 |

操作栏右侧的「当前匹配 N 题」会随难度/章节筛选实时变化，方便你判断库存够不够。

两种方式可以混用：先一键抽整卷，再按章节/难度换掉不满意的几题，最后逐题勾选。

#### 底部汇总条

页面底部固定一条汇总：`已选 X 题　合计 Y 分　卷面 Z 分`，
并提示「与卷面总分一致 / 超出 N 分 / 还差 N 分」。**绿底表示刚好 100 分。**

勾选与分值改完必须点**保存试卷**才生效（保存后按 单选→判断→简答→实操 自动重排题号）。

### 第 3 步：分配考生

- 勾选班级整体添加（显示每班人数）
- 或按学号逐个填（逗号/换行分隔）
- 「追加」保留已有名单，「清空后重建」重新来过

### 第 4 步：发布

点**发布试卷**后，考试状态变为「待开考」。此时仍可撤回修改。

## 五、监考

考试看板 → 选考试 → **开考**。

- 开考后全体考生的计时同时开始，不可暂停
- 收卷时间 = 开考时间 + 时长，到点系统自动收卷
- 中途可**统一收卷**（强制提交所有人），也可对单个考生**强制交卷**
- 考场临时延时：在「延长」框填分钟数，点延长，会把全卷收卷时间与在线考生的个人截止时间一起顺延

看板会实时显示每个考生的状态、剩余时间、客观分、主观分、附件数、切屏次数。

## 六、阅卷

看板 → 进入阅卷。三栏布局：

- **左栏**：已交卷考生列表，显示每人已评题数
- **中栏**：学生作答原文，实操题还会显示任务要求、附件（图片点击放大，其它类型点击下载）
- **右栏**：按评分点打分

打分技巧：

- 每个评分点旁有「满分 / 0」快捷键
- 输入框里按 `Tab` 跳到下一个评分点
- `Ctrl+Enter` = 保存并进下一题
- 点「保存并下一题」会自动找该生下一道未评的题；该生评完则自动跳到下一个有未评题的考生
- 评语可选，教师可见（当前版本不对学生展示）

**所有主观题都评完之后**，该生状态才从「已交卷·待阅」变成「已阅卷」，总分才会汇总出来。只评一部分时总分显示为「—」，这是有意的。

## 七、导出成绩

看板右上角：

- **导出成绩 CSV**：UTF-8 带 BOM，Excel/WPS 直接打开不乱码
- **导出成绩 Excel**：`.xls`（HTML 表格格式），双击用 Excel/WPS 打开后可另存为 xlsx

导出列包含：学号、姓名、班级、状态、开始/交卷时间、用时、交卷方式、切屏次数、**附件数**、每题得分、客观分、主观分、总分。

## 八、系统设置

| 设置项 | 说明 |
|---|---|
| 站点名称 | 登录页与所有页顶栏显示 |
| 学校名称 | 登录页副标题 |
| 切屏次数告警阈值 | 超过该次数学生端会弹提醒，次数记入看板 |
| 单个附件上限（MB） | 实操题单文件上限，受 php.ini 限制 |
| 每题附件最多个数 | 实操题每题最多几个附件 |
| 首次登录强制改密码 | 关掉后学生可直接用初始密码进场 |

## 九、常见操作问答

**想换一道题怎么办？**
组卷页取消勾选原题、勾选新题，点保存试卷。注意总分要回到 100。

**想改某题分值？**
组卷页直接改题后的分值输入框；同一题型批量改用「统一分值 + 套用到已选」。

**考试已经开考了还能改卷吗？**
技术上可以，但会造成同场考生卷面不一致，**强烈不建议**。要改就在开考前改。

**学生说附件传不上？**
依次检查：单个文件是否超过上限 → 是否已达每题个数上限 → 扩展名是否被拒（`.php/.html/.svg` 等会被拒，提示里会写）→ php.ini 的 `upload_max_filesize`。

**学生忘带笔记本交不了附件？**
可以先在题目里让他写清命令与结果，事后由教师补录成绩；或让他在考场机上操作完，用手机拍照后拷到考场机再上传。
